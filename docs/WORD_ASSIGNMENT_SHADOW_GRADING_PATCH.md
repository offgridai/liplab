# Word Assignment Shadow Grading Patch

Diagnostic-only patch. No runtime playback behavior changes.

Adds Python-side grading for `word_assignment_shadow.csv` generated by the shadow word-assignment path.

## New per-case output

When `scripts/summarize.py` or `scripts/check_grades.py` loads a case with gold data and `word_assignment_shadow.csv`, it writes:

- `word_assignment_shadow_grade.json`

The shadow grader:

- deduplicates repeated per-update shadow rows into a hypothetical append-only committed track;
- uses the first eligible row for each planned event;
- preserves absolute playback-space `shadow_start`, `shadow_center`, and `shadow_end` timestamps;
- grades against MFA/gold viseme events with monotonic pose-aware matching;
- computes word span metrics against gold `words.csv`;
- reports contract diagnostics from the shadow rows.

## New summary line

`scripts/summarize.py` now prints:

```text
WORD_ASSIGNMENT_SHADOW cases=... match_rate=... center_ms=... word_f1=... word_duration_l1_norm=... contract_violation_rows=... order_violations=...
```

Per-case summary rows also include compact shadow fields when available:

```text
shadow_matched=... shadow_center_ms=... shadow_word_f1=... shadow_word_duration_l1_norm=...
```

## Purpose

This lets us compare:

- live committed runtime track
- direct aligner upper bound
- shadow word-assignment candidate track

without changing live playback.

Promotion rule remains unchanged: do not swap shadow into the live committed-track producer until the shadow grade beats the live committed path and has zero contract violations.
