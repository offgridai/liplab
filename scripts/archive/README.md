# Archived LipLab experiment scripts

These scripts are retained as research notes, not as current workflow entry points.

They come from older punctuation, occupancy, duration-handoff, and oracle-alignment experiments. They should not be used to judge the current shared runtime unless deliberately revived as a new thesis.

Current default workflow scripts remain in `scripts/`:

- `run_all.py`
- `summarize_run.py`
- `compare_runs.py`
- `extract_liplab_inputs_from_offgrid_logs.py`
- `score_planner_quality.py`
- `select_regressions.py`
- active model-training scripts
